# 🏠 MINI OFFICE WORLD

나만의 작은 세상, 아바타들이 일하는 미니 회사 (개인용 업무관리 PWA)

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm run build   # 빌드
```

## 진행 상황

- [x] 1단계: 파스텔 2층 미니어처 하우스 + SVG 아바타 5명 + 모바일 화면
- [x] 2단계: 아바타 이동 및 생활 기능
- [x] 3단계: 업무 등록 시스템
- [x] 4단계: 아바타 업무 연동
- [ ] 5단계: 일정관리 시스템
- [ ] 6단계: 디자인·편의성 고도화
