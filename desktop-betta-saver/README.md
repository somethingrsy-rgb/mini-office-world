# 🐟 베타 화면 보호기

바닷속 그림 위를 분홍 베타 1마리와 보라 베타 1마리가 헤엄쳐요. 듀얼 모니터면 두 화면에 걸쳐서 나와요.

## 설치 (윈도우)
1. 깃허브 **Actions → Desktop betta screensaver (Windows) → Run workflow**, 끝나면 Artifacts의 `Betta-Screensaver`를 받아요.
2. 압축을 풀면 `Betta-Screensaver.scr`이 있어요. 마우스 오른쪽 버튼 → **설치**를 누르면 화면 보호기 설정 창이 열려요.
3. 목록에서 "Betta-Screensaver"를 고르고 대기 시간(예: 5분)을 정해요.
   - 직접 확인하려면 `.scr`을 더블클릭하거나 설정 창의 "미리 보기"를 누르세요.
   - 안 보이면 `.scr` 파일을 `C:\Windows\System32`에 복사해 보세요.
4. 처음 실행하면 윈도우 보안 경고가 뜰 수 있어요. "추가 정보 → 실행"을 누르세요.

## 동작
- 마우스를 움직이거나 아무 키나 누르면 끝나요. 시작 직후 1.5초는 마우스 움직임을 무시해요.
- 물고기는 위쪽 물빛과 아래쪽 모래 사이에서만 헤엄쳐요. 속도는 보통이고, 크기는 6마리 모두 가장 작은 크기로 같아요.
- 두 마리가 얼굴과 얼굴로 마주치면 둘 다 꼬리를 활짝 펼쳐요.
- 작은 미리보기 칸(설정 창)은 지원하지 않고, 설정 항목은 없어요.

## 그림 바꾸기
- 배경은 `bg.webp`(가로로 긴 그림)이에요. 같은 이름으로 바꿔서 다시 빌드하면 돼요.
- 물고기 그림은 데스크펫 베타와 같아요 (`tools/process_betta.py`로 만든 `frames/`).
