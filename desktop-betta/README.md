# 🐟 베타 물고기 바탕화면 펫

모니터 전체를 아주 천천히 헤엄치는 베타 물고기예요. 인터넷이 없어도 실행돼요.

## 쓰는 법 (윈도우)
1. 깃허브 **Actions → Desktop betta (Windows) → Run workflow**로 exe를 만들고, 맨 아래 Artifacts의 `Betta-Fish`를 받아요.
2. 압축을 풀고 `Betta-Fish.exe`를 더블클릭해요. (설치가 필요 없어요)
3. 작업표시줄 오른쪽 아래(`^` 안쪽)의 **물고기 아이콘**을 누르면 설정 메뉴가 나와요.

## 동작
- 모든 모니터를 돌아다녀요. 기본은 아주 천천히(초당 약 16px)이고, 목표 지점에 가까워지면 더 느려지다가 잠깐 쉬고 다음 곳으로 가요.
- 가는 방향에 따라 좌우를 바라보고, 위아래로 갈 때는 살짝 기울고, 가만히 있을 때도 위아래로 조금 떠올라요.
- **물고기를 더블클릭**하면 꼬리를 활짝 펼쳐요 (약 2.4초). 그동안은 거의 멈춰서 떠 있어요.
- 물고기 모양이 있는 곳만 클릭돼요. 나머지는 뒤 창으로 통과해서 업무에 방해되지 않아요.

## 트레이 메뉴
- 베타 숨기기/보이기 (`Ctrl+Alt+B`)
- 마리 수: 1 / 2 / 3마리
- 크기: 작게 / 보통 / 크게
- 헤엄 속도: 아주 천천히(기본) / 조금 느리게 / 보통
- 시작할 때 자동 실행
- 종료

## 만든 방법
- 그림: `tools/src_art/betta_swim.webp`(헤엄 20장), `betta_flare.webp`(꼬리 펼치기 24장)
- `python3 tools/process_betta.py` → `frames/*.webp`와 `dims.js`(그림 크기, 클릭 판정용 모양 지도)를 만들어요.
- 실행해 보기: `npm install` 후 `npx electron .` / exe 만들기: `npm run dist`
- 안 뜰 때는 `%APPDATA%\betta-desktop-pet\betta.log`를 확인해 보세요.
