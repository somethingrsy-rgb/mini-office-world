# 루비·크리스탈 바탕화면 고양이

화면 아래쪽(작업표시줄 위)을 돌아다니는 아기 고양이 두 마리(루비, 크리스탈)예요. 둘 다 같은 규칙으로 움직여요. 인터넷이 없어도 실행돼요.

둘이 걷다가 우연히 마주치면 1분에 한 번쯤 장난을 쳐요(살금살금 다가간 뒤 코 인사·앞발 톡톡·장난 걸기·쫓고 쫓기기·뒹굴기 중 두 가지를 골라 해요, 조합이 20가지예요). 코 인사·앞발 톡톡은 고양이 한 마리 폭의 0.75배(보통 크기에서 약 100px), 나머지는 1.2배 간격으로 해요. 일부러 서로를 쫓아다니지는 않아요. 장난이 끝나면 1초만 멈춰 있다가 다시 돌아다녀요. 알람이 울리면 장난을 멈추고 뛰어다녀요.

## 사용법
- `고양이.exe`를 더블클릭하면 고양이가 나타나요. 설치가 필요 없어요.
- 고양이를 **누르면** 애교를 부려요.
- **마우스를 가까이** 가져가면 앞발로 잡으려 해요.
- 고양이가 없는 곳은 클릭이 뒤에 있는 창으로 그대로 통과해서 업무에 방해되지 않아요.
- 작업표시줄 오른쪽 **트레이 아이콘**을 누르면 숨기기, 크기, 시작할 때 자동 실행, 종료를 고를 수 있어요.

## 기능
- **모든 창 위에 표시:** 한글, 엑셀 등으로 바꿔도 루비가 화면 위에 계속 보여요. 루비 주변은 투명해서 뒤 문서가 그대로 보여요.
- **화면 아래 산책:** 작업표시줄 바로 위를 걷다가 앉거나 앞발을 핥아요.
- **창 위에 올라앉기:** 열려 있는 창의 위쪽 테두리로 폴짝 뛰어올라 앉아요. 창을 옮기면 따라가고, 창을 닫으면 바닥으로 내려와요.
- **마우스에 반응:** 포인터를 코앞에서 흔들면 앞발로 잡으려 하고, 재빨리 빼면 헛짚고 고개를 갸웃해요.
- **원하는 곳에 두기:** 루비를 드래그해서 화면 구석이나 다른 모니터에 놓을 수 있어요. 놓으면 아래 면으로 떨어져 앉아요.
- **클릭 통과:** 루비 모양이 있는 곳만 눌려요. 셀이나 버튼을 가려도 그 자리를 누르면 뒤 문서가 클릭돼요.
- **잠시 숨기기:** 발표나 화면 공유 때 `Ctrl+Alt+H` 또는 트레이 메뉴로 숨겼다가 다시 불러요.
- **알람:** 정각 알림, 타이머, 사용자 알람. 울리면 루비를 누를 때까지 뛰어다녀요.

## 만드는 법
GitHub의 **Actions → Desktop cat (Windows) → Run workflow**를 누르면 `고양이.exe`가 만들어져요. 완료되면 그 실행 결과 맨 아래 **Artifacts**에서 내려받아요.
직접 만들려면(윈도우 PC): `cd desktop-cat && npm install && npm run dist` → `dist/고양이.exe`
미리 보기: `npm install && npm start`

## 그림을 바꾸려면
`frames/`의 webp 파일과 `dims.js`(그림 크기)를 같은 이름으로 교체해요. 원본은 앱 저장소의 `tools/process_cats.py`로 만들어요.

## 안 뜰 때
1. **zip을 풀었는지** 확인하세요. zip 안에서 바로 실행하면 안 돼요.
2. 같은 실행 결과에 **고양이.exe(한 파일)** 와 **고양이-folder.zip(폴더 형태)** 두 가지가 있어요. 한 파일이 막히면 폴더 형태를 풀어서 안의 `고양이.exe`를 실행해 보세요.
3. 시작하면 오른쪽 아래에 "루비가 시작됐어요" 알림이 떠요. 안 뜨면 `%APPDATA%\ruby-desktop-cat\ruby.log` 파일(메모장)을 열어 마지막 줄을 알려주세요.
4. 처음 실행할 때 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.

## 업무 중에 쓰는 기능
- **고양이 불러서 놀게 하기** (트레이 메뉴 또는 `Ctrl+Alt+C`): 마우스가 있는 모니터의 바닥 가운데로 두 마리가 와서 장난쳐요. 25초 안에 못 오면 그 자리로 불러요.
- **집중 모드** (트레이 메뉴 또는 `Ctrl+Alt+F`): 고양이가 작아져서 오른쪽 아래 구석에 앉아 가만히 있어요. 정각 알림은 소리·폴짝 없이 말풍선만 보여요(알람·타이머는 그대로 울려요). 끄면 원래대로 돌아가요.
- **전체 화면 자동 숨김**: 영상·발표·게임처럼 맨 앞 창이 모니터 전체를 덮고 제목 표시줄이 없으면 고양이를 숨겼다가, 끝나면 다시 보여요. (`Ctrl+Alt+H`로 직접 숨긴 건 그대로 유지돼요)
- **시작할 때 자동 실행**: 트레이 메뉴에서 켜고 끌 수 있어요.
- **열려 있는 창 위에 올라가기**: 트레이 메뉴에서 켜고 끌 수 있어요. 끄면 창 위로 폴짝 올라가지 않고 바닥에서만 돌아다녀요(창 위에 있던 고양이도 바닥으로 내려와요).
- **정각 LED**: 정각이 되면 모든 모니터의 테두리가 연두색 LED처럼 빛나요. 테두리(가장자리 약 18px)를 누르면 사라져요. 안 눌러도 10분 뒤에 꺼져요. 정각 알림을 끄면 LED도 안 나와요.
- **18:00 e-사람 체크**: 18시 정각에는 LED와 함께 두 고양이가 뛰어다니고 말풍선에 "e-사람 체크"가 떠요. LED 테두리나 고양이를 누르면 멈춰요. 집중 모드에서는 뛰지 않고 말풍선만 떠요.
- **고양이 오른쪽 클릭 → 타이머**: 고양이를 마우스 오른쪽 버튼으로 누르면 5·10·20·30·60분 타이머 메뉴가 떠요. 고르면 시작하고, "타이머 취소"로 끌 수 있어요.
- **타이머 남은 시간 표시**: 고양이를 오른쪽 클릭해서 타이머를 시작하면 그 고양이 머리 위에 `⏱ 4:59`처럼 남은 시간이 떠요 (돌아다녀도 따라다녀요). 타이머를 시작한 고양이에게만 보이고, 두 마리가 각자 다른 타이머를 따로 맞출 수도 있어요. 이미 맞춘 고양이를 다시 오른쪽 클릭하면 "타이머 취소 (남은 시간)"이 나와요. 트레이 메뉴·설정 창에서 시작한 타이머는 보이는 첫 고양이(루비)가 맡아요.
